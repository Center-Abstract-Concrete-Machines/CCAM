To use gen~ on a hardware device, one good solution is the Daisy microcontroller. It is flexibile in ways that other hardware situations (such as Raspberry Pi and Bela) are not. It is also relatively inexpensive. You might consider using a CCAM EARTH (3v3) or ESTUARY (+/-12v Eurorack module), which are built on Daisy Seed and Daisy Patch SM microcontrollers, respectively.

To get Gen~ on a Daisy, you need to use a package called Oopsy. Below are various resources and communities for getting started with Daisy and Oopsy.
