# Splash Rotator Images

Drop images in this folder to control the homepage rotating splash images.

Supported formats:
- jpg
- jpeg
- png
- webp
- avif
- gif

Behavior:
- If this folder contains at least 1 image, the homepage splash rotators use only images from this folder.
- If this folder is empty, the app falls back to the existing configured behavior.

Tip:
- Use smaller source images when possible to keep bandwidth lower.
